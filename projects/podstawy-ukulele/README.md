# Podstawy ukulele: source art

Raw generations, prompts, job logs and build scripts behind `MusicGames/ukulele-warmup/art/podstawy/`
(the basics film for first-time ukulele players, `ukulele-warmup/podstawy.html`). The finished WebPs
and their README live in MusicGames; this folder is everything that made them.

- `prompts/`, `jobs/`, `*.log`: what was asked and what came back (gpt-image-2, Nano Banana, gpt-image GIFs via APIYI).
- `r1`…`r6`, `gif/`, `keyed/`, `cut/`: the rounds, including rejected tries.
- `build.py`, `build_strips.py`: the cut, key and strip build into the shipped files.
- `art-review.html` / `.png`: every shipped asset on a checkerboard, with strips playing and the JSON overlays.
