# Leszy (gondar/MathGames, klasa 7) — publiczne referencje dla MiniMax-H3

H3 przyjmuje tylko publiczne HTTPS, a repo MathGames jest prywatne, więc referencje filmu „Leszy” leżą tutaj
i są podawane przez `https://cdn.jsdelivr.net/gh/gondar/sprite-refs/refs/leszy/<plik>`. Nigdy nie nadpisujemy pliku —
nowa wersja dostaje nową nazwę.

- `wstawki/` — pierwsze klatki (bez tekstu) wstawek wideo: a 5–9 s, b 125–130 s, c 137–141 s.
- `lis/` — wzorce lisa-wędrowca do animacji z manekinów.
- `leszy/` — wzorce Leszego (cień z mgły z porożem) do animacji z manekinów.
